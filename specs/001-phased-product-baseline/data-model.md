# Data Model: Phased Product Baseline

Postgres 16, Drizzle schema in `packages/db/src/schema.ts`, one SQL migration per phase.
Conventions: `id uuid` primary keys (UUID v7 generated by the client for expenses, by the server
elsewhere), `created_at`/`updated_at timestamptz`, every user-owned table has
`user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE` and an index starting with
`user_id`. Money columns are `bigint` minor units; rates are `numeric(20,10)`; currency codes are
`char(3)` validated against the ISO 4217 table in core.

## Phase 1: accounts

**users** (exists from Phase 0; extended)
- `id`, `email citext UNIQUE NOT NULL`, `email_verified_at timestamptz NULL`,
  `password_hash text NULL` (null for Google-only accounts), `default_currency char(3) NOT NULL`,
  `theme text NOT NULL DEFAULT 'system'` (system | light | dark), `time_zone text NOT NULL
  DEFAULT 'UTC'` (IANA name, taken from the browser at sign-up), `onboarding_completed_at
  timestamptz NULL`, `created_at`, `updated_at`.
- Unverified users (`email_verified_at IS NULL`) older than 7 days are purged by `housekeeping`.
- Rule: a user has a password hash or at least one `oauth_accounts` row.

**oauth_accounts**
- `id`, `user_id`, `provider text` ('google'), `provider_subject text`, `email_at_link citext`,
  `created_at`. UNIQUE `(provider, provider_subject)`.

**sessions**
- `id uuid`, `user_id`, `token_hash bytea UNIQUE`, `created_at`, `last_seen_at`,
  `expires_at`, `user_agent text`, `ip inet NULL`, `revoked_at timestamptz NULL`.
- Index `(user_id, expires_at)`. `expires_at` is the earlier of last seen + 30 days and created +
  90 days. Lifecycle: active → revoked (logout, reset, delete) or expired.

**email_tokens**
- `id`, `user_id`, `purpose text` ('verify' | 'reset'), `token_hash bytea UNIQUE`,
  `expires_at` (verify 24 h, reset 20 min), `used_at timestamptz NULL`, `created_at`.
- Rule: single use; `used_at` set in the same transaction as the action.

**rate_limits**
- `key text`, `window_start timestamptz`, `count int`. PRIMARY KEY `(key, window_start)`.
  Rows older than one hour are pruned by the `housekeeping` job.

**fx_rates** (shared, not user-owned)
- `rate_date date`, `base char(3)`, `quote char(3)`, `rate numeric(20,10)`, `source text`
  ('frankfurter'), `fetched_at`. PRIMARY KEY `(rate_date, base, quote)`.

**jobs**
- `id`, `name text`, `user_id NULL` (null for system jobs), `payload jsonb`, `status text`
  (queued | running | done | failed), `run_after timestamptz`, `started_at`, `finished_at`,
  `progress_done int DEFAULT 0`, `progress_total int NULL`, `error text NULL`, `attempts int`.
- Index `(status, run_after)`. Transitions: queued → running → done | failed; failed → queued on
  retry while `attempts < 5`.

**flags** and **user_flags**
- `flags(key text PRIMARY KEY, description text, default_on boolean)`.
- `user_flags(user_id, key REFERENCES flags, enabled boolean, PRIMARY KEY (user_id, key))`.

**audit_log**
- `id`, `user_id NULL`, `actor text` (user | system | job), `action text`, `subject text`,
  `details jsonb`, `created_at`. Append-only; connector actions, refused capture messages and
  account deletions land here; on account deletion `user_id` is replaced by a one-way hash and
  rows are purged after 12 months.

## Phase 2: expenses

**categories**
- `id`, `user_id`, `name text`, `colour text`, `default_kind text NULL` (fixed | variable |
  one_off), `budget_minor bigint NULL` (in the user's default currency), `sort_order int`,
  `archived_at timestamptz NULL`, timestamps. UNIQUE `(user_id, name)`.
- Seeded on sign-up with the 18 defaults from CLAUDE.md; "Other" cannot be deleted.

**expenses**
- `id uuid` (client UUID v7 allowed), `user_id`, `category_id REFERENCES categories ON DELETE
  SET NULL` (application reassigns to "Other" before deleting a category), `description text`,
  `expense_date date`, `paid_with text` (card | cash | bank_transfer | other),
  `kind text` (fixed | variable | one_off), `notes text NULL`,
  `amount_original bigint`, `currency_original char(3)`,
  `rate_to_default numeric(20,10) NULL`, `rate_date date NULL`, `rate_source text NULL`,
  `amount_default bigint NULL`, `rate_overridden boolean DEFAULT false`,
  `added_via text` (dashboard | notion | phone | import), `import_batch_id uuid NULL`,
  `notion_page_id text NULL`, `notion_last_edited_at timestamptz NULL`,
  `deleted_at timestamptz NULL`, timestamps.
- Indexes: `(user_id, expense_date)`, `(user_id, deleted_at)`, `(user_id, category_id)`,
  UNIQUE `(user_id, notion_page_id)` where not null.
- Rules: `amount_default IS NULL` only while a rate is awaited; when `currency_original =
  default_currency` the rate is 1 and `rate_date = expense_date`; `rate_overridden` implies
  `rate_source = 'user'`. Lifecycle: active → binned (`deleted_at` set) → restored (cleared) or
  purged by `housekeeping` after 30 days.

**import_profiles**
- `id`, `user_id`, `name text`, `mapping jsonb` (columns for date, amount, currency,
  description, category, id; `date_format`, `decimal_separator`, `header_rows`),
  timestamps. UNIQUE `(user_id, name)`.

**import_batches**
- `id`, `user_id`, `profile_id NULL`, `file_name text`, `row_count int`, `status text`
  (previewing | importing | done | undone | failed), `created_expenses int`, `duplicates int`,
  `errors int`, `created_at`, `finished_at`.

**import_rows**
- `id`, `batch_id REFERENCES import_batches ON DELETE CASCADE`, `user_id`, `row_number int`,
  `raw jsonb`, `parsed jsonb NULL`, `fingerprint bytea NULL`, `external_id text NULL`,
  `status text` (ok | duplicate | error | skipped), `error text NULL`, `expense_id uuid NULL`.
- Index `(user_id, fingerprint)`; duplicate check compares against existing expenses'
  fingerprints computed in core and against `external_id` when the profile maps an id.

## Phase 3: Notion and capture

**notion_connections**
- `id`, `user_id UNIQUE`, `workspace_id text`, `workspace_name text`, `bot_id text`,
  `access_token_enc bytea` (AES-256-GCM, key from env), `database_id text NULL`,
  `data_source_id text NULL`, `direction text` (to_notion | from_notion | both),
  `status text` (connected | error | disconnected), `last_sync_at`, `last_error text NULL`,
  `cursor timestamptz NULL`, timestamps.
- Transitions: connected ↔ error (per sync outcome); any → disconnected (user action, keeps
  expenses and clears `access_token_enc`).

**expense_versions**
- `id`, `expense_id REFERENCES expenses ON DELETE CASCADE`, `user_id`, `source text`
  (app | notion | sync_conflict), `snapshot jsonb`, `edited_at timestamptz`, `created_at`.
- Written on every sync-applied change and on conflicts (both sides); purged after 12 months.

**capture_tokens**
- `id`, `user_id`, `token_hash bytea UNIQUE`, `label text` ('generic'), `created_at`,
  `revoked_at timestamptz NULL`, `last_used_at`. One active token per user per label.

**capture_receipts**
- `token_id REFERENCES capture_tokens ON DELETE CASCADE`, `receipt_key text`,
  `expense_id uuid`, `received_at`. PRIMARY KEY `(token_id, receipt_key)`.

**capture_category_map**
- `user_id`, `label text`, `category_id REFERENCES categories ON DELETE CASCADE`.
  PRIMARY KEY `(user_id, label)`.

## Phase 5: operations

**feedback**
- `id`, `user_id NULL`, `page text`, `message text`, `contact_ok boolean`, `user_agent text`,
  `created_at`.

## Derived views (queries in core, not tables)

- Month summary: sum of `amount_default` where `deleted_at IS NULL` grouped by category for a
  `(user, YYYY-MM)`; budget comparison from `categories.budget_minor`.
- Forecast: spend to date plus remaining fixed-kind budgets not yet incurred this month.
- Export document: shape defined in `contracts/api.md` (`GET /me/export`).

## Cascade and isolation guarantees

- Deleting a user cascades through every table above except `fx_rates` and `flags`.
- No query in `apps/api` reads a user-owned table without a `user_id = $current` predicate;
  the ownership matrix test in `apps/api/test/ownership.test.ts` exercises every route with two
  users and asserts 404 or an empty list for foreign ids.
