## Decisions made this session (binding unless Rostom reopens them)

- **Credential format:** sealed plaintext is JSON `{ refreshToken }`. The bytea holds the UTF-8 bytes of the base64 SecretBox string, as in `notion.ts`. Both directions go through `apps/api/src/lib/credential.ts` (`sealCredential`/`openCredential`). This fixed two Phase 2 bugs: the callback's `'test-token'` fallback, and the refresh job's `Buffer.from(sealed,'hex')` re-seal. The re-seal is still in `panels-refresh.ts` and T034 must switch it to `sealCredential`.
- **No refresh token** at the callback redirects with `error=provider_unreachable` and writes no row.
- **Mockable OAuth hosts:** optional `GOOGLE_OAUTH_BASE` and `MICROSOFT_LOGIN_BASE`. Unset means the real hosts.
  - Google base B gives `${B}/o/oauth2/v2/auth`, `${B}/token` and `${B}/revoke`.
  - Microsoft base B gives `${B}/common/oauth2/v2.0/{authorize,token}`.
  - Helpers: `googleOAuthEndpoints`/`microsoftOAuthEndpoints` in `lib/credential.ts`, passed through `AppDeps`.
  - `worker.ts` doesn't set them, because Stage 2 uses the real hosts.
- **e2e-ci seeds connected accounts through Postgres** (5432 is exposed in compose and CI) with the compose SecretBox key, and doesn't run the browser OAuth round-trip. The OAuth vars stay single values pointing at `http://mocks:4000/...` from inside the container. The callback itself is covered by API tests.
- **Calendar sources are factories:** `createGoogleCalendarSource`/`createMicrosoftCalendarSource({ clientId, clientSecret, apiBase, oauthEndpoints?, fetchImpl })`. Each call refreshes the access token itself. Microsoft returns `rotatedCredential: { refreshToken }`. The job calls `fetchWindow` once per calendar, because cursors are per calendar.
- **`fetchWindow` results gained `deletedIds?: string[]`**, filled by incremental fetches (Google cancelled items, Graph `@removed`). T034 must delete those rows on partial fetches.
- **Time conventions:** timed events are exact instants with an exclusive end. All-day events run from UTC midnight of the first date to UTC midnight of the exclusive end date, and `expandToDays` buckets them by UTC date whatever the zone.
- **Fakes** (`GoogleFake`, `GraphFake`) hold provider-shaped raw items seeded from the fixtures, expose `rawCalendars()`/`rawEvents(calendarId)` for the mock HTTP servers (T036), and ignore cursors.
- `PanelFrame` is still absent, so `PanelState.vue` stays. Brief 5 goes before Brief 6 in Wave 2.
